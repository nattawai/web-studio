# Web Direction

## เสนอสไตล์
2–3 ตัวเลือก ภายในอารมณ์ที่ brief กำหนด แต่ละตัวใช้ `preview` ระบุ: สี (hex), ฟอนต์ (EN + TH), แนว parallax, ความรู้สึก

## ตรวจ contrast ทันทีหลังเลือก
- สีพาสเทล/กลางมักไม่ผ่าน AA สำหรับตัวหนังสือ → เพิ่มเฉด "-ink" ที่เข้มกว่าสำหรับข้อความ
- ระบุในตาราง token ว่าสีไหน "ห้ามใช้เป็นตัวหนังสือ"

## ผลลัพธ์ `docs/design.md`
- ตาราง color tokens (token, hex, ใช้กับ, หมายเหตุ contrast)
- typography
- motion rules + motion plan ต่อ section
- QA criteria
